## 已完成的修复

### compute-1 管理网恢复

错误方法：

```bash
sudo ip link set enp7s0 up
sudo ip addr flush dev enp7s0
sudo ip addr add 172.16.0.101/24 dev enp7s0
```

这组命令短时间有效，但 NetworkManager 会把地址清掉。

正确方法：

```bash
sudo nmcli connection modify "有线连接 1" \
  connection.autoconnect yes \
  ipv4.method manual \
  ipv4.addresses 172.16.0.101/24 \
  ipv4.gateway "" \
  ipv4.never-default yes
sudo nmcli connection up "有线连接 1"
```

恢复后确认：

```text

ipv4.method:                            manual
ipv4.addresses:                         172.16.0.101/24
ipv4.gateway:                           --
ipv4.never-default:                     是
```
